# tiny-french-gpt

Petit modèle de langage (GPT decoder-only, ~25M de paramètres) entraîné from scratch sur un corpus français (Wikipédia sciences + Project Gutenberg littéraire).

## Objectif
Construire de zéro un chatbot miniature : tokenizer BPE, pré-entraînement, SFT sur dialogues, génération.

## Statut
En cours de développement.
